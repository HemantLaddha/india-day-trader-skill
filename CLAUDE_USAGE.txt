Indian Day Trader Skill Pack - Claude Usage Guide
=================================================

This repository is the Indian-market version of the day-trader-skill project.
It contains skill docs and Python tools for NSE/BSE trading workflows.

How to use it in Claude
-----------------------

1. Open this repo folder as the active project/workspace in your Claude-capable environment.
2. Make sure the repo root is the working directory.
3. Ask Claude to use a specific skill, for example:
   - "Use the trader-alerts skill."
   - "Use the trader-analyst skill to analyze Reliance."
   - "Use the trader-scanner skill to review watchlist ideas."
   - "Use the trader-timemachine skill to replay a planned trade."

4. If you want actual script output, run the Python files directly from the terminal:

   cd day-trader-skill-main-indian-market
   py -3 trader-alerts/alerts.py --json
   py -3 trader-analyst/facts.py RELIANCE --json --quarters 2
   py -3 trader-timemachine/timemachine.py --help

Important notes
---------------

- The markdown SKILL files are instruction files for the AI workflow.
- The real behavior comes from the Python scripts in each trader-* folder.
- This repo is designed for local use in a Claude-enabled environment.
- The cloud-only Claude UI may not directly execute your local Python scripts unless your environment supports local tool access.
